# Armonya — landing page

Landing page single-page per Armonya, biorisonanza a distanza per cani e
gatti. React + Vite + TypeScript + Tailwind v4 + Motion.

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
